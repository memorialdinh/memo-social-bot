Connect Accounts

Turns your Meta access token into the three values the bot needs.
This page runs entirely in your browser. Your token is sent only to Meta's own API (graph.facebook.com) to look up your Page and Instagram IDs. Nothing is stored, logged, or sent anywhere else. Close the tab and it's gone.
  1. In the Graph API Explorer, click Generate Access Token and approve your Page + Instagram.
  2. Click Copy Token there.
  3. Paste it below and press Get my values.
  4. Copy each value into GitHub → Settings → Secrets and variables → Actions.
